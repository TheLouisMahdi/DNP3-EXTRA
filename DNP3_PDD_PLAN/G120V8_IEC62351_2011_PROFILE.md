# G120V8 / IEC/TS 62351-8:2011 - normative extraction

Reviewed: 2026-11-10. Source: supplied 48-page **IEC/TS 62351-8:2011 Edition 1.0** (physical PDF pages equal printed pages + 2), supplied IEEE 1815-2012, RTU Device Profile and security addendum. This is a standards/source audit, NOT a runtime verification or a new contractual requirement set.

## Contract and role boundary

- Selected: `PROFILE-055` (G120V8), with dependent `CFG-03`, `SEC-T1-01/14/15/16/17`, `SEC-T2-04/10` and the selected G120V10-V15 key-change procedures. Preserve all 119 contractual IDs; do not add IEC role-based features absent a necessary selected dependency.
- **IEC/TS 62351-8:2011 is now available and inspected**. Do not continue classifying its text itself as missing. RFC 5280, RFC 5755 and the applicable IEC/TS 62351-3 revocation profile still need *pre-implementation* standards verification.
- IEC Clause 1, printed pp8-9 explicitly excludes choosing production trust authorities, key enrollment/exchange, engineering and assignment of roles, passwords and local organizational policy. No standard can supply a real RTU identity, AoR, production CA/AA or independent peer evidence.
- IEEE A.45.8 only allows the **ID certificate (IEC Profile A)** and **attribute certificate (IEC Profile B)** for G120V8, not IEC Profile C software token. The Master relays authority-signed data unchanged; it is not the issuing authority.
